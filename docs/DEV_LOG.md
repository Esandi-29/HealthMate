# HealthMate development log

Problems met during development, what caused them and how they were fixed.
This is the source for the report's **Issues/Errors & Fixes** section (5.3). Newest entries at the bottom.

**Types:** `Build` (Gradle/compile) · `IDE` (Android Studio) · `Git` · `Design` (a technical decision) · `Env` (emulator/tools, not the app)

| ID | Date | Task | Type | Problem | Cause | Fix |
| --- | --- | --- | --- | --- | --- | --- |
| DL-01 | 19 Oct 2026 | 1.6 | IDE | The New Project wizard did not create the project inside the cloned `HealthMate` folder; the window kept showing only README and .gitignore. | Android Studio will not generate a new project into the folder it currently has open (the cloned repo). | Created the project in a temporary `HealthMate2` folder, copied it into the clone with `cp -R HealthMate2/. HealthMate/`, then opened `HealthMate`. |
| DL-02 | 19 Oct 2026 | 1.6 | Git | "Line Separators Warning: you are about to commit CRLF line separators" on the first commit. | The template's Windows script `gradlew.bat` uses Windows (CRLF) line endings. | Chose *Fix and Commit*, which set `git config --global core.autocrlf input` so files are stored with Unix (LF) endings. |
| DL-03 | 19 Oct 2026 | 1.6 | Git | Android Studio asked for a Git user name and email before committing. | Git had never been configured on this Mac, and every commit needs an author. | Set name and GitHub email globally in the prompt. |
| DL-04 | 19 Oct 2026 | 1.6 | Git | First push failed: `java.net.http.HttpConnectTimeoutException`. | Android Studio was not signed in to GitHub; the connection timed out during authentication. | Logged in with *Log In via GitHub* (OAuth for JetBrains IDE Integration), then pushed again successfully. |
| DL-05 | 20 Oct 2026 | 2.1 | Design | Needed library versions compatible with the very new Android Gradle Plugin 9.4 and its built-in Kotlin. | AGP 9 removes the separate Kotlin plugin and is incompatible with `kapt`; Room needs an annotation processor. | Used KSP 2.3.11 (KSP 2.3.1+ supports AGP 9 built-in Kotlin) with Room 2.8.5; versions taken from the official AndroidX stable-channel page. |
| DL-06 | 20 Oct 2026 | 2.1 | IDE | Pre-commit check reported 17 errors after adding the libraries, although the app ran. | Gradle had not been re-synced, so the IDE did not know the new libraries ("Gradle files have changed since last project sync"). | Clicked *Sync Now*; errors disappeared and the build succeeded (KSP and Room schema tasks ran). |
| DL-07 | 20 Oct 2026 | 2.5 | IDE | *Build → Generate APKs* produced an unsigned `app-debug.apk` and never asked for a signing key. | That menu item builds the debug variant; signing has a separate menu item. | Used *Build → Generate Signed App Bundle or APK*, created `HealthMate-release.jks` outside the project, built `app-release.apk` (1.1 MB). Keys and release builds added to `.gitignore`. |
| DL-08 | 20 Oct 2026 | 2.2 | Build | Converting the Space Grotesk variable font to a static SemiBold (600) file failed: `Cannot find Axis Values {'wght': 600}`. | The font's STAT table has no named entry for weight 600, so the tool could not rename the instance. | Generated that weight without rewriting the name table (`updateFontNames=False`); all 9 font files then created and checked visually. |
| DL-09 | 20 Oct 2026 | 2.2 | Design | Several palette colours were too light for text/icons on a white background (e.g. Orange O2 2.3:1, Bright Blue BL2 3.0:1). | WCAG 2.1 requires 4.5:1 for text and 3:1 for icons/graphics. | Light theme uses deeper palette shades (Tangerine O3, Strong Blue B2) plus derived Deep Mint/Pink/Amber; dark theme uses the bright originals. |
| DL-10 | 20 Oct 2026 | 2.2 | IDE | Red error in MainActivity: "Argument type mismatch: actual type is '() -> Unit', but ComposableFunction0 was expected", while the app still compiled and ran. | A theme object and the theme function were both named `HealthMateTheme`, which confused the IDE's analyser. | Renamed the object to `HealthMateStyle` (`HealthMateStyle.metrics`, `HealthMateStyle.numbers`). |
| DL-11 | 20 Oct 2026 | 2.2 | Git | The commit almost went out without the 31 new files (fonts, icons, new Kotlin files); the message box also kept the previous commit's text. | New files sit under *Unversioned Files*, which must be ticked separately; Android Studio pre-fills the last message. | Ticked *Unversioned Files* and checked the `+added *modified` counter before every commit; cleared the message box each time. |
| DL-12 | 19–20 Oct 2026 | — | Env | Emulator popups: "Process system isn't responding" and "Google Play services keeps stopping". | Emulator system apps starting slowly; not caused by HealthMate. | Tapped *Wait* / *Close app*; no change needed in the app. |
